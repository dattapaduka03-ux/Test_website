🚀 QUICK START (3 STEPS):

  1. EXTRACT THE ZIP FILE
     → Unzip ashram_website_complete.zip to your desired location

  2. OPEN IN VS CODE
     → File → Open Folder → Select ashram_website folder
     → Or: code ashram_website (in terminal)

  3. INSTALL & RUN
     → Open Terminal in VS Code (Ctrl + `)
     → Type: pnpm install
     → Type: pnpm run dev
     → Open: http://localhost:3000

❓ TROUBLESHOOTING:

  Q: Images not showing?
  A: Ensure all 8 images are in client/public/images/
     Check that filenames match paths in Home.tsx

  Q: "Port 3000 already in use"?
  A: Vite will automatically use next available port
     Check terminal for actual URL

  Q: npm install fails?
  A: Clear cache: npm cache clean --force
     Then try again: npm install

  Q: TypeScript errors?
  A: Run: pnpm run type-check
